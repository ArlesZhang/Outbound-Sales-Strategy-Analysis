## 项目概述

本项目是对外呼销售策略的数据分析项目，旨在通过数据驱动的方法优化销售流程、提升转化率。

### 核心分析维度

1. **销售漏斗分析**：从线索获取到成交的全链路转化率
2. **客户分层**：基于 RFM 模型的客户价值分层
3. **销售效率**：销售人员绩效分析、最佳实践提炼
4. **策略优化**：基于数据发现的销售策略建议
